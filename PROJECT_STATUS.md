# Project Status — Myceliyum

**Portfolio class:** Flagship  
**Maturity:** **Application prototype / active**  
**Platform:** Native Android (Kotlin / Jetpack Compose)  
**Last portfolio review:** 2026-08-13

## What is demonstrated

- Native Android application architecture in Kotlin/Jetpack Compose.
- offline-first local data with Room.
- maps/location integration with OpenStreetMap/osmdroid and Play Services Location.
- REST/API integration for public species and weather/environmental data.
- Retrofit/Moshi/OkHttp networking patterns.
- camera/file-sharing flows through Android platform APIs.
- release/signing/build workflow work and iterative migration of the Android toolchain.

## Evidence boundary

This is a real application prototype, not a scientific prediction system. Suggestions about likely fruiting zones are decision-support outputs built from available environmental/species data and should not be represented as validated ecological forecasting.

Optional cloud/AI components are integrations, not evidence that the app depends on or uniquely authors those external models/services.

## Authorship / AI assistance

Authored MAZLABZ application developed with AI coding agents as part of the engineering workflow. AI assistance has supported implementation, research, debugging and refactoring; product definition, architecture, integration and verification remain the project owner's responsibility.

## Portfolio takeaway

Myceliyum is one of the clearest general-audience examples of end-to-end product work: **native mobile UI + local persistence + maps + location + APIs + release tooling**.
